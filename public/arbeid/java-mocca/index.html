Java & Mocca

To kaféer, to logoer og ett felles uttrykk som kundene tar med seg ut døra.

KundeJava & Mocca
BransjeKaffebar, Oslo
LeveranseLogo · Kopper · Profil
Utfordringen

Mocca Briskeby og Java St. Hanshaugen trengte logoer som passet atmosfæren i kaféene, og som fungerte der kundene faktisk ser dem: på koppen.

Løsningen

Jeg tegnet nye logoer for begge kaféene og designet take-away-koppene, slik at de fikk et helhetlig og gjenkjennelig uttrykk. Det visuelle uttrykket er godt mottatt og løfter kaféenes identitet i et marked med mye konkurranse.
